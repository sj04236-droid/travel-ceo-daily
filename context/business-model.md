## 1. 서비스 정의

> 강점: 목적이 분명한 방문자(박람회 날짜가 정해진 출장자, 반려동물 동반이 필수인 보호자)라 예약으로 이어질 가능성이 일반 여행 정보보다 높다고 본다(가정). 약점: 제휴 수수료만으로는 단가가 낮아 방문자 규모가 필요하고, 일정·동반 가능 여부 정보가 틀리면 신뢰를 잃는다.

| 항목 | 내용 |
|------|------|
| 분야 (니치) | 테마 여행 정보 도구(일정·조건 검색) + 여행 제휴 딥링크 + 광고 |
| 타깃 고객 | ① 박람회·전시회 참관 출장자·바이어·자영업자 ② 반려동물 동반 국내 여행자 |
| 첫 수익 목표 시점 | 2~3개월 (검증 전 가정) |
| 최종 단계 목표 월매출 | 3,000,000원 (검증 전 가정) |

### 고객이 겪는 문제 (이 서비스가 푸는 것)

- **박람회·전시회:** 일정은 주최 측 사이트에, 항공·호텔은 예약 사이트에, 전시장 가는 길은 또 다른 곳에 흩어져 있다. "이 전시회 기간에 전시장 근처 호텔과 항공을 한 번에" 보고 싶다.
- **반려동물 동반:** 숙소·식당·관광지마다 동반 가능 여부, 크기 제한, 추가 요금이 달라 하나씩 전화하거나 후기를 뒤져야 한다. "이 지역에서 우리 개와 갈 수 있는 숙소·식당·관광지"를 한 화면에서 보고 싶다.

### 차별점 (남이 못 따라하는 이유)

- 종합 여행사를 약 20년 운영하며 항공권 예약·발권을 직접 해 온 경력 → 출장 일정에 맞는 항공·에어텔 조합, 변경·환불 주의점을 정보에 녹일 수 있다.
- 여행 제휴 딥링크 엔진, 호텔 데이터, 항공 최저가 조회가 **이미 내 사이트에 작동 중** → 새 테마는 "데이터 + 화면"만 얹으면 된다.
- 단순 목록이 아니라 "일정·조건 → 바로 예약"까지 한 화면에서 이어지는 세련된 화면(UI·UX)을 목표로 한다.

## 2. 핵심 기능 명세

이 서비스의 핵심 기능입니다. 우선순위 = 나열 순서.

### 기능 1. 테마 A — 박람회·전시회 일정 허브

- **내용**: 국내·해외 박람회·전시회를 날짜·도시·산업별로 검색. 각 전시회 페이지에 기간, 장소, 공식 사이트 링크, 정보 확인 날짜 표시.
- **목적 (푸는 불편)**: 흩어진 일정 확인 + 출장 준비를 한 곳에서
- **수익 연결**: 전시회 기간·도시에 맞춘 **에어텔(항공+호텔)·호텔·렌터카·공항픽업 제휴 딥링크** (트립닷컴, 아고다, 마이리얼트립, 클룩 등)
- **데이터 후보(이용 가능 여부 확인 필요)**: 공공데이터포털의 전시회·해외전시회 정보, 주요 전시장 공개 일정

### 기능 2. 테마 B — 반려동물 동반 국내여행 지도

- **내용**: 지역을 고르면 동반 가능한 숙소·식당·관광지를 지도와 목록으로. 크기 제한·추가 요금 등 조건 표시.
- **목적 (푸는 불편)**: 하나씩 전화·검색하던 확인 작업을 한 화면으로
- **수익 연결**: **국내 숙소·투어 제휴 딥링크** + 반려동물 여행용품(쿠팡) + 광고
- **데이터 후보(이용 가능 여부 확인 필요)**: 한국관광공사 TourAPI의 반려동물 동반여행 정보

### 기능 3. 테마 공통 틀 (새 테마를 설정만으로 추가)

- **내용**: "데이터 수집 → 정리 → 화면 → 제휴 연결"을 하나의 틀로 만들어, 다음 테마(예: 축제, 온천, 무장애 여행)를 설정 파일만 바꿔 추가.
- **수익 연결**: 테마 수가 늘수록 유입 문과 제휴 연결 지점이 늘어남

### 기능 4. 운영 엔진 — 분석까지 도는 AI 자동화 시스템

- **내용**: 지금 흩어져 있는 내 자동화(블로그 발행, 쓰레드, 쇼츠, 서치콘솔 리포트)를 하나의 구조로 묶고, **매주 숫자 6개(노출 → 클릭 → 체류 → 제휴클릭 → 전환 → 수익)** 를 자동으로 모아 "무엇을 고치고 무엇을 늘릴지"까지 제안받는다.
- **목적**: 글을 많이 찍는 자동화가 아니라, **결과를 보고 스스로 개선하는 자동화**
- **수익 연결**: 직접 매출은 아니지만 위 1~3번의 전환을 올리는 장치. 장기적으로 이 운영 방식 자체를 다른 여행사·1인 사업자에게 제공할 수 있음.

## 3. 수익화 & 가격

- 수익화 방식: 제휴수수료 / 트래픽광고 / (나중에) 전시 출장 맞춤 상담

| 결제 항목 | 단가 |
|-----------|------|
| 여행 제휴(호텔·에어텔·렌터카·투어) | 예약액의 일정 비율 — 프로그램마다 다름, 가입 후 대시보드에서 확인 |
| 구글 광고 | 방문자 수에 비례 |
| 쿠팡 등 용품 제휴 | 판매액의 일정 비율 |
| 전시 출장 맞춤 수배·상담 (나중에) | 건당 과금, 가격 미정 |

## 4. 채널 (유입·판매)

- 검색(구글·네이버), threads, youtube_shorts, instagram(카드뉴스), 기존 내 사이트(travel·hotel·airticket)의 내부 링크
- 반려동물 테마는 사진·영상 공유가 잘 되는 채널, 박람회 테마는 검색과 업종 커뮤니티가 맞을 것으로 본다(가정).

## 5. 단계별 실행 로드맵

1단계부터 순서대로. 각 단계의 "다음 단계 신호" 도달 시 다음 단계로 확장.

### 1단계 — 테마 1개, 지역·기간을 좁혀 작동하는 화면 만들기

두 테마 중 **데이터를 구하기 쉬운 쪽 1개**만 고른다. 범위도 좁힌다(예: 반려동물 = 제주·강원만 / 박람회 = 앞으로 3개월 내 국내 주요 전시장만). 손에 쥐는 것: 실제 데이터가 나오는 페이지 + 제휴 딥링크가 붙은 화면. 흔한 실패는 데이터 없이 글로만 채우는 것과, 처음부터 전국·전 세계를 다 하려는 것.

- 이 단계 매출 목표: 100,000원 (첫 제휴 전환 발생이 목적, 검증 전 가정)
- 단계 완료 시 확보 자산: 작동하는 테마 페이지 + 데이터 수집 스크립트 + 제휴클릭 기록
- 다음 단계 신호: 검색 노출이 잡히고 제휴클릭이 주 10회 이상 → 2단계. 4주간 클릭이 0이면 테마 또는 범위 교체.

### 2단계 — 두 번째 테마 추가 + 유입 채널 연결

1단계에서 만든 틀을 재사용해 두 번째 테마를 붙이고, 쓰레드·쇼츠·카드뉴스로 유입을 만든다. 손에 쥐는 것: 테마 2개 + 테마별 유입 채널 1개씩 + 주간 숫자 6개 자동 수집.

- 이 단계 매출 목표: 1,000,000원 (검증 전 가정)
- 단계 완료 시 확보 자산: 테마 공통 틀 + 주간 숫자 자동 보고 + 어떤 테마·채널이 전환되는지에 대한 데이터
- 다음 단계 신호: 테마 1개 이상에서 제휴 전환이 매주 발생 → 3단계.

### 3단계 — 분석이 돌아가는 자동 시스템으로 완성 ★ 최종

데이터 갱신·콘텐츠 배포·성과 수집·개선 제안이 자동으로 돌고, 나는 승인과 새 테마 기획만 한다. 전환이 검증된 테마에 한해 전시 출장 맞춤 상담 같은 직접 서비스를 붙인다.

- 이 단계 매출 목표: 3,000,000원 (검증 전 가정)
- 단계 완료 시 확보 자산: 자동 갱신되는 테마 여행 정보 허브 + 스스로 개선하는 운영 시스템 + 제휴·광고 수익
