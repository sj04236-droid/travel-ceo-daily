# 쓰레드 작업 규칙 (브랜드 규칙 `../../AGENTS.md` 다음에 읽기)

- 이용층: 30~60대가 많음. 짧고 읽기 쉽게, 한 문단 2~3줄.
- 말투: **반말**(쓰레드 암묵적 문화). 친근하게, 훈계·과장 없이. 일상 댓글은 더 가볍게(드립 허용, 비방·혐오·정치 금지).
- **본문에 링크 넣지 않기.** 필요하면 첫 댓글 또는 "프로필 링크"로 안내.
- 이 계정은 새 계정(2026-10 개설). 기존 자동 발행 계정(sns_caption)과 섞지 않는다.

| 폴더 | 하는 일 | 방식 |
|---|---|---|
| `daily-comment/` | 피드 상위 인기 글에 사람 같은 일상 댓글 → 프로필 노출 | 웹브라우징 (API 없음, 39강). 처음엔 내가 확인 후 게시 |
| `promo-comment/` | "항공권·수하물·환불" 고민 글을 찾아 답 + 자연스럽게 내 정보 연결 | 키워드 검색(공식 API) |
| `posts/` | 게시글(정보·경험담·실패담) | API 예약 발행 |

- 댓글 말투 규칙은 공통 스킬 `../../../공통/skills/natural-sns-comment/`(39강에서 만듦)를 쓴다.
- 작업 기록은 각 폴더 `log/YYYY-MM-DD.md`.
